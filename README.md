# Cosmic Planet Maker

Android offline game project (Java + WebView), package `com.cosmic.planetmaker`.

## Add the project ZIP
Upload the file `CosmicPlanetMaker_Android_Project.zip` to the repository root. The GitHub Actions workflow extracts it and builds a debug APK.

## Build
Open the **Actions** tab and run **Build Cosmic Planet Maker APK** (or upload the ZIP to trigger it).

When complete, open the successful workflow run and download the artifact named `cosmic-planet-maker-debug-apk`. Extract the artifact ZIP to get `app-debug.apk`.

The APK is a debug build. Install and test it on an Android device before sharing.
